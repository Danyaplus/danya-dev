Article Studio

Вход в редактор карточек для блога Kodumi TG Bots.

Локальный генератор HTML. Это демонстрационный вход на стороне браузера, не защищённая серверная авторизация. Не храните здесь секретные данные.
GitHub Pages не умеет сам записывать новые статьи в сайт. Эта админка генерирует готовые HTML-карточки для трёх языков.

Новая статья

Заполни русскую, украинскую и английскую версии. Потом нажми генерацию — получишь сразу 3 карточки: для index.html, ua/index.html и en/index.html.

Общие настройки карточки

Если загружаешь свою картинку, код будет содержать её прямо внутри карточки. Это удобно, но если картинка огромная, HTML станет тяжёлым.

Куда вставлять

Каждую карточку вставляй самой первой после строки:

<div class="blog-track" id="blogTrack">

Так новая статья станет первой слева, а старые будут уходить вправо и листаться стрелками.
